## 📜 О проекте

**Story Clicker** — сюжетный 2D-кликер в сеттинге мрачного королевства Арканум, павшего под натиском «Изумрудной Чумы». В роли последнего Странника Ордена Очищения игрок с зачарованным руническим клинком пробивается сквозь искажённых созданий и древние катакомбы.

---

## ✨ Особенности демо-версии

* 📖 **Сюжетный пролог:** кинематографичное построчное появление истории и лора перед началом похода.
* ⚔️ **2 уникальных уровня и босса:**
  * **Уровень 1:** *Опушка Зачарованного Леса* — **Мастер Илларион** (Чумной Слизень-Алхимик).
  * **Уровень 2:** *Катакомбы Цитадели* — **Сир Мордред** (Падший Страж Катакомб с руническим двуручником).
* 🛒 **Интерактивная выдвижная лавка улучшений:**
  * *Острота клинка* (+клик урон).
  * *Золотые пальцы* (+золото за клик, лимит 2 уровня).
  * *Скверный яд* (автоматический периодический урон в секунду).
  * *Монетница* (пассивный приток золота).
* ⚙️ **Система сложности:** выбор Лёгкой, Средней и Сложной сложности с динамическим масштабированием здоровья монстров.
* 🎵 **Звук и музыка:** раздельная регулировка громкости звуковых эффектов и фоновой музыки.
* 📚 **Бестиарий:** файл `BESTIARY_LORE.md` с глубокой предысторией каждого создания.

## 🚀 Установка и запуск

### 1. Требования
Убедитесь, что у вас установлен Python 3.10 или новее.

### 2. Установка зависимостей
```bash
pip install pgzero pygame
```

### 3. Запуск игры
```bash
python main.py
```
или через встроенный раннер Pygame Zero:
```bash
pgzrun main.py
```

* **Левая кнопка мыши (ЛКМ):** атака монстра, покупка улучшений, открытие/закрытие шторки лавки, навигация по меню.
